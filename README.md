# 🚀 Yogeshwaran S — Developer Portfolio

A modern, production-ready developer portfolio built with React, TypeScript, Tailwind CSS, and Framer Motion.

Designed with a premium UI/UX approach inspired by modern SaaS products and interactive developer portfolios.

---

## 🌐 Live Demo

🔗 https://yogeshwarans-portfolio.vercel.app/

---

## ✨ Features

- Modern responsive UI
- Dark / Light theme
- Smooth Framer Motion animations
- Interactive project showcase
- Scroll progress indicator
- Active section navigation
- Mobile-first design
- SEO optimized
- Reusable component architecture
- Type-safe codebase with TypeScript

---

| Category | Technology |

## ⚙️ Getting Started

### Clone Repository

```bash
git clone <your-repo-url>
cd yogesh-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

---

## 📦 Production Build

```bash
npm run build
```

---

## 🚀 Deployment

### Vercel

```bash
vercel
```

### Netlify

Deploy the generated `dist/` folder.
